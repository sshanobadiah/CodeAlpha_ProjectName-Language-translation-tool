 Language Translation Tool
 
A simple and interactive Language Translation Web App built using Python and Streamlit. This tool allows users to translate text between multiple languages instantly.

🚀 Features
🔤 Translate text between multiple languages

🌐 Supports:
English
Tamil
Hindi
French
Spanish

⚡ Fast and easy-to-use interface
🖥️ Built with Streamlit for a clean UI
⚠️ Input validation (warns if text is empty)
🛠️ Technologies Used
Python
Streamlit
deep-translator (GoogleTranslator)
